# Security policy

This is experimental software that handles SSH credentials. Source publication is not a production
security certification. See README.md and the validation records for tested behavior and remaining
physical-device, optimized-runtime and Play acceptance limits.

Please report vulnerabilities privately through GitHub's **Report a vulnerability** feature when
available. Do not put private keys, passwords, server addresses, billing receipts, device logs, or
personal information in public issues. Include a minimal reproduction using disposable credentials.

Only the latest source is maintained. There is no guaranteed response time or supported production
release yet. Keep independent backups of software keys; Android Keystore private keys cannot be
exported. Use only trusted commands in the local fallback shell, which shares the application's UID.
